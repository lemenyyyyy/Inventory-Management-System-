# Contributing

Thanks for considering a contribution to Chocolate Apocalypse!

## Development setup

1. Fork the repository.
2. Clone your fork.
3. Create a virtual environment.
4. Install dependencies with `pip install -r requirements.txt`.
5. Configure your local `.env`.
6. Run the application and tests.

## Pull requests

Please keep changes focused and include tests where practical.

Before opening a pull request:

```bash
pytest
```

Avoid committing credentials, `.env` files, generated local inventory files, or IDE configuration.
